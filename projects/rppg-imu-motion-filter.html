Motion-Robust Heart Rate Estimation via rPPG–IMU Sensor Fusion

Context: BME Course Project · University of Oulu
Domain: rPPG · IMU · Signal Processing
rPPG IMU Sensor Fusion Heart Rate Estimation Signal Processing Android

Smartphone-based remote photoplethysmography (rPPG) can estimate heart rate from facial video without any contact, but deliberate hand motion while holding the phone introduces severe artifacts that corrupt the signal. This project investigates whether co-located accelerometer and gyroscope data — already available on any smartphone — can be used to detect and filter these motion-corrupted windows, recovering estimation accuracy when the subject moves.

Sub-Millisecond Sensor Synchronization

Fusing camera-derived rPPG with IMU streams requires the two data sources to be precisely time-aligned. To achieve this without specialized hardware, the system emits acoustic chirp pulses from the laptop speakers, captured by the phone's microphone, to align the Android device's hardware timestamps with the laptop's performance counter — reaching synchronization accuracy with R² > 0.9999997. A validation experiment confirmed the chirp pulses introduce negligible IMU artifact (0.18 m/s² versus 1.31 m/s² for typical hand motion).

rPPG Extraction & Motion Filtering

Facial regions are tracked with MediaPipe FaceLandmarker, and blood volume pulse signals are extracted using three established rPPG algorithms from the pyVHR library — CHROM, POS, and OMIT — over 6-second sliding windows with 0.65–4.0 Hz bandpass filtering. To counter motion artifacts, three IMU-driven strategies were implemented and compared: Normalized LMS adaptive filtering, motion-gated window rejection, and IMU-weighted signal fusion. Ground-truth heart rate was collected in parallel via a Beurer PO-80 pulse oximeter over USB HID.

Results

Across 8 subjects using the CHROM method, motion roughly tripled the estimation error relative to a stationary baseline. Gating out IMU-flagged corrupted windows recovered a meaningful share of that lost accuracy:

ConditionMean Absolute Error
Still (baseline)5.6 ± 2.7 bpm
Motion (no filtering)18.6 ± 9.4 bpm
Motion + IMU gating filter16.8 ± 8.1 bpm
